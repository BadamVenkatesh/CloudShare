# CloudShare Project

## Overview
**CloudShare** is a full-stack file sharing and storage application designed to provide secure, fast, and user-friendly file management. It leverages a modern tech stack to handle file uploads, user authentication, and subscription-based storage plans.

## System Architecture

The project consists of two main components:

1.  **Frontend (`cloudShare`)**: A Single Page Application (SPA) built with **Vite** and **React**. It handles the user interface, interaction with the backend API, and integration with Clerk for authentication and Razorpay for payments.
2.  **Backend (`cloudShareapi`)**: A RESTful API built with **Spring Boot** and **MongoDB**. It manages business logic, file metadata, user credits, and payment verification.

### External Services
-   **Clerk**: User Authentication and Management.
-   **Razorpay**: Payment Gateway for subscriptions.
-   **MongoDB Atlas**: NoSQL Database for storing metadata and user info.
-   **FileSystem/Cloud Storage**: Actual file content storage (currently configured for local/server storage).

## Quick Start
To run the full stack locally, you need to start both the frontend and backend servers.

### 1. Backend Setup
Navigate to the `cloudShareapi` directory:
```bash
cd cloudShareapi
./mvnw clean install
./mvnw spring-boot:run
```
*The backend server will start on port `9090`.*

### 2. Frontend Setup
Navigate to the `cloudShare` directory:
```bash
cd cloudShare
npm install
npm run dev
```
*The frontend server will start on `http://localhost:5173`.*
